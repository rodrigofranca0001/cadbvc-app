# e-SUS CADBVC — app Android

Arquivo de instalação do app da UBS de Boa Vista do Cadeado (cadastros dos ACS e situação dos sistemas).
O código fica em repositório privado; o uso exige login.

**Baixar a versão atual:** [cadbvc.apk](https://github.com/rodrigofranca0001/cadbvc-app/raw/main/cadbvc.apk)

No celular: abra o link no Chrome, toque no arquivo baixado e permita instalar. Versão nova: instale por cima (os dados não se perdem).
